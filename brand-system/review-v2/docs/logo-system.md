# Logo system — review 02

The primary source is `../assets/logo/primary-source.png`, generated using Nano Banana MCP, Gemini 3 Pro Image, 2048 × 2048. The name reads “Dum E” / “Odisha.” This is generated custom-looking lettering, not a commercial typeface or a human illustrator's commission.

Exports: `primary.png`, `mono.png`, `reversed.png`, all 1788 × 1418 RGBA raster files. `avatar.png` is the same lid symbol cropped from that source, fitted into a 512 × 512 cream canvas; `favicon.png` is a 48 × 48 derivative. JPEG proofs flatten onto the intended grounds. The export script performs background/ink separation and colour normalization without redrawing letter geometry. Exact source and resulting export are both retained.

Primary uses chilli #852D26 with saffron #E8A535; mono uses ink #29231F; reversed uses cream #FFF6E7. Keep the lockup intact. No restacking, replacing letters, stretching, new tile around E, added tagline inside the mark or recolouring from arbitrary CSS. Place the existing tagline as separate live text.

Clearspace: at least 8% of lockup width around the exported image. Recommended minimum digital width: 180 px for the full name; 240 px is more comfortable. Use the lid at 32 px or more with a separate readable name. The 48 px favicon is a browser derivative, not a claim that the full name works at 16 px. Small-size actual exports are recorded in the proof sheet.

At 300 ppi, 1788 px supports about 151 mm across the full raster. Treat 140 mm as a conservative upper review size; it is not an approved print size or a guaranteed production minimum. Do not upscale for signage. A designer should reconstruct clean editable vector outlines from the chosen source after the owner's creative decision, preserving letterforms, DUM/E separation, counters, symbol angle and lockup proportions. Compare raster and vector at large and small scales before replacing the canonical artwork.

No file is labeled vector when it contains raster art. The HTML application templates are editable layouts, with embedded raster logos. No trademark/similarity clearance or physical substrate testing is claimed.

## Round 03: a symbol without lettering

[The Handi Host](../explorations/round-03/handi-host.html) is a new pictorial logo with no name, initials or alphabetic monogram. A welcoming cooking pot, lifted lid, steam and rice shapes carry the subject. The transparent 1254 × 1254 colour PNG is the original built-in image-generation output. The 1024 × 1024 white-background stamp is a separately generated Nano Banana simplification; its contours differ. Both are raster review concepts, with actual 128/96/48 px comparison on the page. At 48 px the face and rice lose detail; prefer 96 px or more for the stamp and reconstruct vectors for print.

[Hindi](../explorations/round-03/hindi.html) and [Odia](../explorations/round-03/odia.html) experiments pair this symbol with typeset name units; each also supplies a pure wordmark alternative. Eight transparent 1600 × 700 PNG compositions and their HTML sources are available. Sources preserve live script text; the placed symbol remains raster. No final selection or native approval is claimed.
