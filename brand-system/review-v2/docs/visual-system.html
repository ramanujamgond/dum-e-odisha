Visual system — review 02

17 October 2026 · Working identity

All values are sRGB digital targets. Generated illustration pixels are textured approximations, not flat spot inks. CMYK/profile conversions need a printer, substrate and physical proof. Contrast calculations are in the actual validation results.

Type: Georgia/Times New Roman/serif for expressive headings, Georgia italic for a softer voice; Arial/Helvetica/sans-serif for labels and practical information. The main identity uses system fonts. Four separately licensed Noto binaries are bundled only for the Odia/Hindi exploration type lab; see localization-kit.html. Body 17 px / 1.6; captions 12–14 px; headings scale 38–64 px in the guide. Logo lettering is image artwork and is not typeset again on applications.

Layout: generous cream areas, a quiet rule, a strong hero and varied section rhythms. Use an 8 px spacing base; common gaps 24, 32, 40 and 64. Avoid wrapping every piece into rounded UI cards. Supporting illustration is a large still life, never a pattern behind small text. Crops keep the pot and lid recognisable. Wordmark stays on a quiet field.

Icon system: the actual cropped lid is the sole brand symbol. Functional navigation uses text labels rather than decorative icon libraries. Dietary or allergen information must be written in words after verification; colour does not carry these facts alone.

Motion: no autoplay, parallax or attention loops. Anchor scrolling respects reduced-motion preferences. Dark/light, monochrome, compact and narrow-screen variations are tested separately in the proof record. This is a working proposal, pending the owner's design review.
