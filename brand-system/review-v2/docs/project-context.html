The historical source remains intact.

Round 03: pictorial and mixed-script experiments

The owner supplied a long Dribbble screenshot and explicitly requested one image-only logo plus Hindi and Odia mixed-word logos. The new Round 03 collection contains a lettering-free Handi Host, a Hindi beginning and an Odia ending, with initial/middle/end variants for both scripts. Built-in image generation created the transparent character; Nano Banana created a simpler one-ink interpretation. Mixed-script words use actual bundled Noto fonts with Latin Georgia and preserve complete Unicode strings. These are requested explorations, not final adoption.
